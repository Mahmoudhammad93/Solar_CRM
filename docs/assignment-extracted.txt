    2. Product brief and end-to-end workflow
    Create a centralized CRM for a solar EPC/installation business. It should connect sales, field survey, hybrid system sizing,
    quotations, execution, inventory, service, analytics and a broad dynamic settings center.


      PRIMARY WORKFLOW
      Lead -> follow-up/qualification -> customer/site visit -> hybrid solar calculation ->
      quotation/proposal -> accepted quotation -> sales order/project -> materials/team allocation ->
      installation milestones -> commissioning/handover -> invoice/payment visibility -> service
      ticket/AMC.


    Minimum quality expectations
     • Use consistent navigation, clear page titles, search/filter controls, validation messages, useful empty/loading/error states and
       responsive forms.

     • Use linked records rather than duplicate disconnected entries: a lead/customer should link to visits, calculations, quotations,
       orders/projects, documents and tickets.

     • Use unique reference IDs for leads, visits, quotations, orders/projects, products, invoices, tickets and AMC contracts.

     • Use stored data to calculate dashboard metrics and reports. Do not use decorative hard-coded KPIs.

     • Dynamic business configuration belongs in the Settings tab and database. Changing a setting must affect the relevant UI,
       calculations, templates, exports or workflows without code edits or redeployment, where technically applicable.

     • If an external service such as WhatsApp, email, GPS/maps, e-signature, live subsidy data or payment gateway is not
        integrated, label it as Demo/Simulated and document production setup.

    4. Solar calculators and calculation rules
    The calculator is a key evaluation area. It must not return arbitrary or fixed results. Show inputs, formulas/assumptions,
    intermediate totals, units, final estimate and a printable/exportable report. Results are indicative estimates, not an
    engineering certification.

    A. Hybrid solar calculator (replaces separate off-grid and on-grid calculator
    requirements)
     • Load table: appliance/load name, quantity, rated watts, hours/day, usage pattern, critical/non-critical classification and
       optional starting/surge factor. Calculate connected load, daily energy (Wh/kWh) and peak simultaneous load.

     • Solar and utility inputs: average monthly units and/or bill, tariff per unit, usable roof area, proposed PV capacity, panel
       wattage, peak sun hours or generation assumption, performance ratio/system loss factor, self-consumption assumption, grid
       availability and export/net-metering assumption where applicable.

     • Battery/inverter inputs: backup duration target, system voltage, battery chemistry, nominal battery capacity, usable depth of
       discharge, battery/inverter efficiency, inverter continuous and surge rating, charge-controller/inverter limits and optional
       generator input.

     • Financial inputs: panel/inverter/battery/BOS prices, GST rate, installation, transport, structure/civil work, wiring/protection,
       engineering, other charges, O&M, and editable subsidies/export rates where applicable.

     • Outputs: recommended PV kWp and panel count, roof-area-constrained system size if enabled, daily/annual energy estimate,
       battery nominal and usable kWh/Ah requirement, inverter rating, estimated backup time, expected solar contribution,
       grid/generator support assumptions, self-consumed/exported units if configured, cost breakdown, total estimate and PDF
       report.

     • Display each selected input, unit and assumption beside results. Do not apply one universal battery/inverter rule without
       showing the inputs and calculation path.

     • If real tariff, net metering or subsidy rules are used, show applicable state/utility, source/reference and effective date.
        Otherwise mark all such values Sample/Demo and make them editable in Settings.

     • Use configurable formulas and documented assumptions. Validate physical plausibility, non-negative values, units, efficiency
       ranges and zero denominators. State when detailed engineering validation is required.

    B. Solar investment / income calculator
     • Inputs: upfront cost, applicable grant/subsidy, optional loan amount/interest/tenure, estimated generation, self-consumption,
        export price, utility tariff, degradation, tariff escalation, annual maintenance and other recurring costs.

     • Outputs: net initial investment, monthly/annual savings or revenue, annual operating cost, net cash flow, payback period, ROI
       for a selected period and an assumptions report. NPV/IRR are bonus items.

    C. EV charging income calculator
     • Inputs: charger type/power (kW), number of charging points, sessions/day, average kWh/session, operating days/month,
        selling price, electricity purchase cost, utilization, rent/staff/maintenance/other monthly costs and optional capital cost.

     • Outputs: energy sold, gross monthly/annual revenue, electricity cost, operating expenses, estimated net profit, utilization
       assumptions, break-even and payback estimate when capital cost is provided.

    Calculator acceptance tests
      Test                        Expected behavior

      Hybrid sizing               Changing appliance quantity/hours, backup target, panel wattage, peak sun hours, battery usable depth or
                                  efficiency changes relevant outputs logically.

      Generation/savings          Changing tariff, generation/loss assumption, self-consumption or export rate changes projected savings and
                                  payback.

      Cost estimate               Changing product prices, GST, installation or transport updates line items and total; generated PDF matches
                                  on-screen results.

      Validation                  Reject negative inputs, implausible efficiencies, invalid denominators and non-numeric inputs; show
